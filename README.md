# Gerenciador de Tarefas

Programa em Python que roda no terminal e ajuda a organizar tarefas do dia a dia.

## O que ele faz

- Adiciona novas tarefas
- Lista todas as tarefas
- Marca tarefas como concluídas
- Remove tarefas
- Salva tudo em um arquivo, então nada se perde ao fechar o programa

## Tecnologias

- Python 3
- Módulos json e os (já vêm com o Python)

## Como rodar

1. Instale o Python 3
2. Baixe este projeto
3. No terminal, dentro da pasta do projeto, rode:

```
python main.py
```
